# seperkarbs-piso-print-web
SEPERKARBS PISO PRINT is a coin-operated printing kiosk. Customers upload a PDF or image from their phone, see the page count and price, insert peso coins, and press Print. The kiosk shows the bond paper left, warns the owner on Telegram when paper or ink runs low, and lets customers send a photo with their GCash details to request a refund.
